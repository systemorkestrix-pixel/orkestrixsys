# 14. VISUAL DIRECTION

صفحة Projects يجب أن تكون:

**Visual-first**

المستخدم يجب أن يرى المشروع قبل أن يبدأ القراءة.

* Clean mockups
* device previews
* generous whitespace
* restrained borders
* subtle shadows
* consistent image ratios

لا تجعل كل مشروع يبدو كأنه بطاقة صغيرة.
